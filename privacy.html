PesangonCVKita PP 35/2021
Kalkulator AI Bedah Surat

Kebijakan Privasi (UU PDP)

Terakhir diperbarui: 20 November 2026.

1. Kalkulator — 100% lokal di browser

Seluruh angka upah, masa kerja, sisa cuti, dan hasil simulasi pada kalkulator pesangon diproses 100% lokal di browser kamu. Tidak ada data yang dikirim atau disimpan ke server PesangonCVKita. Preferensi input terakhir disimpan di localStorage perangkat kamu sendiri dan tidak pernah meninggalkan perangkat.

2. AI Bedah Surat — diproses sesaat, tidak disimpan

Jika kamu memakai fitur AI Bedah Surat PHK/Resign, teks atau hasil ekstraksi PDF surat dikirim terenkripsi melalui HTTPS ke server API dan penyedia AI (OpenRouter) semata-mata untuk menghasilkan analisis yang kamu minta. Teks surat tidak disimpan di database/KV server dan tidak dipakai untuk melatih model. Kami menyarankan kamu menyamarkan NIK dan nama perusahaan sebelum mengunggah.

3. Data pembayaran & lisensi

Pembayaran fitur Pro diproses oleh Midtrans. Kami hanya menyimpan metadata order (ID order, status, kode lisensi, sisa kuota) yang diperlukan untuk mengaktifkan dan memverifikasi lisensi. Kami tidak pernah menyimpan data kartu/akun pembayaran kamu.

4. Kontak

Pertanyaan tentang privasi: kode@cvkita.id. Dasar hukum pemrosesan mengacu pada UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP).
